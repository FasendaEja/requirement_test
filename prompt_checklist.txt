Составь чек-лист проверок требований по результатам их тестирования.

Входные данные:
1) ОТЧЁТ ПО РЕЗУЛЬТАТАМ ТЕСТИРОВАНИЯ ТРЕБОВАНИЙ — выводы ИИ-аналитика;
2) ИСХОДНЫЕ ТРЕБОВАНИЯ — оригинальный текст файлов требований.

Формат ответа — СТРОГО CSV-таблица с разделителем ";" и заголовком:
Номер;Описание проверки;Результат;Пример вводимого значения

Правила заполнения:
- Каждое существенное требование и каждый выявленный дефект — отдельная
  строка чек-листа. Нумерация сквозная: 1, 2, 3, ...
- «Описание проверки» — конкретное проверяемое действие в терминах
  верификации («Проверить, что ...»), на русском языке, без переносов
  строк внутри ячейки.
- «Результат» — ровно одно из значений:
  успешно              — требование проверено, дефектов нет;
  ошибка               — выявлен дефект / требование не выполнено;
  не применимо         — проверка не требуется в текущем контексте;
  требуется уточнение  — недостаточно информации для проверки.
- «Пример вводимого значения» — конкретные тестовые данные (валидные,
  невалидные, граничные), выводимые из текста требований; если вывести
  нельзя — «нет данных».
- Ячейки, содержащие символ ";", бери в двойные кавычки.
- Никакого текста вне CSV-таблицы: ни вступлений, ни пояснений,
  ни markdown-обёрток ``` ```.
