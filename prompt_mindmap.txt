Построй mind-map (интеллект-карту) по результатам тестирования требований.

Входные данные состоят из двух частей:
1) ОТЧЁТ ПО РЕЗУЛЬТАТАМ ТЕСТИРОВАНИЯ ТРЕБОВАНИЙ — выводы ИИ-аналитика;
2) ИСХОДНЫЕ ТРЕБОВАНИЯ — оригинальный текст файлов требований.

Требования к формату ответа:
- Markdown-список с отступами: 2 пробела на каждый уровень вложенности,
  маркеры "-" (корневой узел — одна строка "#" или "-" без отступа).
- Корень карты: название системы / набора требований (по исходному тексту).
- Ветви верхнего уровня (обязательные):
  * Требования — декомпозиция по модулям/функциям; у каждого требования
    пометка статуса: [успешно], [ошибка] или [требуется уточнение];
  * Дефекты — выявленные проблемы, сгруппированные по типу
    (неполнота, неоднозначность, непроверяемость, противоречие и т.п.);
  * Риски — риски реализации/приёмки, вытекающие из дефектов;
  * Вопросы заказчику — уточняющие вопросы из отчёта.
- Глубина карты — 3–5 уровней; формулировки узлов короткие (до ~10 слов).
- Опирайся ТОЛЬКО на предоставленный отчёт и требования, ничего не выдумывай.
- Верни ТОЛЬКО mind-map: без пояснений, без вступлений, без кода-обёртки ``` ```.
